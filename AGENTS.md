## Clearline project rules

Read `README.md` and `docs/DATA.md` first. Public, open-source harm reduction site.

- **Dark mode only.** Never add a light theme or toggle. Tokens live in `src/app/globals.css`.
- **No hard-coded figures.** Every number comes from `data/*.json` through `src/lib/data.ts`.
- **Privacy is non-negotiable.** Week + broad area only; never names, sellers, venues or exact dates (`docs/DATA.md#privacy-rules`).
- **Demo data** is generated by `bun run seed`; the "Demo data" banner stays until `data/samples.json` has `"demo": false`.
- Status always pairs an icon with a label, never color alone. Charts are hand-written SVG in `src/components/charts.tsx`.
- Proof before done: `bun run lint && bun run build`, then look at changed pages at desktop and 390px widths.
- Keep `CHANGELOG.md` `## Unreleased` current with every change.
